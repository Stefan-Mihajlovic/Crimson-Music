# Favorites artwork

The Favorites header, Home shortcut, Library cards and desktop sidebar share `src/components/favorites-artwork.tsx`. Its default thumbnail variant uses a top-aligned 120% crop with a centered horizontal position: the source heart sits at about 42% height, and this crop puts it at the center of square Home, Library and sidebar artwork. Caller dimensions and rounded corners stay on an outer clipping view, so the Library playing indicator remains centered independently.

Thumbnails keep the six-second animated WebP at `assets/images/favorites/heart.webp`. The Favorites detail screen explicitly uses the `hero` variant, preserving its original framing and using `heart-still.webp` with a smooth 10% scale pulse over 4.4 seconds. The pulse runs with the native animation driver on iOS/Android and stops when the screen loses focus or the app enters the background. Reduce Motion and Performance Mode show the separate still with no pulse, including on web browsers.

The source artwork at `assets/images/favorites/heart-source.png` was created using the built-in imagegen tool. It is retained as the input to `scripts/generate-favorites-artwork.sh`; it is not bundled into the app. The generator creates the thumbnail animation with FFmpeg: a subtle 3% breathing zoom at 640 × 640 and 16 fps, with an infinite loop. The encoder merges identical adjacent frames without changing timing. The more visible hero pulse is controlled in the shared component rather than baked into another image. Run `bash scripts/generate-favorites-artwork.sh` with FFmpeg on PATH, or set `MEDIA_FFMPEG_BIN` to the executable path.

## Original imagegen prompt

> Use case: stylized-concept. Create a production-ready square artwork for the Favorites collection in Crimson Music, a refined dark music player. 1024x1024 square, edge-to-edge artwork only, no UI or text. A single iconic sculpted heart, centered at x=50%, y=44%, occupying about 46% of the image width and 43% height. Smooth volumetric translucent violet glass heart with a rich dark-purple body, luminous purple rim and restrained pearly white-violet highlights; gently beveled dimensional form, frontal with a very slight 3D turn, recognizably a heart at thumbnail sizes. Color palette strictly deep violet #6D28D9, electric violet #965CFF, glow #7C3AED, highlights #B18AFF, near-black #0E0D13; avoid red, pink, magenta and blue. A subtle soft violet halo behind the heart and very few tiny faint violet light specks around it. Spacious almost-black deep-purple atmospheric background, clean and quiet, especially the lower 25 percent where the app will overlay white text. Premium minimal music cover art, soft cinematic studio lighting, polished glass, elegant controlled bloom rather than aggressive neon. No rings, no tunnel, no soundwave, no lettering, no logos, no watermark, no borders. Composition must work both square and center-cropped landscape as a Favorites header. This still will be animated with a subtle slow breathing motion.
